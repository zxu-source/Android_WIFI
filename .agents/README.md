# 代理协作目录

根目录 `AGENTS.md` 是自动发现入口；本目录是入口明确引用的补充材料。不要假定任意 `.agents/` 文件会被开发工具自动加载。

## 布局与阅读路由

| 文件 | 什么时候阅读 | 职责 |
| --- | --- | --- |
| `rules/android.md` | 安卓代码、UI、网络任务 | 分层、状态、权限与客户端验证 |
| `rules/firmware.md` | ESP8266 或接线任务 | 驱动、资源注册、板级约束 |
| `workflows/development.md` | 实施、联调、交付 | 阶段执行与证据记录 |

业务需求、设计、协议、计划和验收的唯一正文放在 `docs/`；这里引用它们，不复制整份内容，以免出现多份不一致的方案。

本轮不添加项目专属 skills、虚构工具权限或子代理角色。未来出现反复执行的稳定流程时再引入专用技能；工具不支持的代理配置不作为“已启用”功能。
