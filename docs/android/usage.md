# 安卓首版安装与操作

## 安装

构建产物：`app/build/outputs/apk/debug/app-debug.apk`。将 APK 传到 Android 手机，按系统提示允许该来源安装，再打开“WiFi 外设遥控”。支持最低系统为 Android 6.0/API23；2026-10-16 已在 Android 17/API37 模拟器中安装运行并完成测试，真实手机仍待验证。

通过 USB 调试安装时，在能找到 adb 的终端运行：

```powershell
adb devices
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

仅安装在用户选择的测试设备；多台设备时使用 `adb -s <serial>`。这是 debug 签名实验版本，不是商店发布版本。

## 无开发板时体验

1. 选择“模拟模式”，点击“连接”。
2. 操作主 LED 开关和调光数值，观察确认状态和等待提示。
3. 室温为模拟只读属性；扩展兼容示例显示未知类型但不可操作。
4. 在“模拟故障测试”选择延迟、断线、驱动失败，或“已执行但响应丢失”。结果未知时 App 读取状态，不自动重发命令。
5. 选择正常模式后刷新恢复；也可模拟下位机重启。断开/重新连接会创建新的模拟设备，恢复初始状态。

模拟模式持续显示标识，不证明真实外设或无线链路工作。

## v1.1：功能清单驱动面板

连接后自动获取下位机清单和状态，再按外设自定义名称和属性能力生成面板，无需额外点击加载。二态开关、范围调节和只读传感分别显示对应控件；风扇与调光复用数值控件，不按设备名字判断。

设备信息卡显示外设数量、可控属性数量、清单版本和获取时间。“更新功能清单”可手动刷新旧固件的改名/改范围；新固件提供匹配的capabilitiesRevision后，App也会自动检测并更新。

模拟模式现在有不同名称的开关灯和风扇。在“模拟故障测试”中点击“模拟新增一盏灯”，清单会多出“床头灯”并出现可操作开关，不需要改App代码。清单为空或获取失败时不虚构控件，不一致时停止写入并提示。

新版APK版本为1.1（versionCode2），签名一致时可覆盖旧版debug安装。对接格式见[功能清单详细规范](../protocol/capability-list.md)。

## 默认网络：手机提供热点

1. 进入手机系统的热点/无线设置，开启手机热点。
2. 后续 ESP8266 固件使用 STA 模式加入该热点，串口输出 DHCP 获得的 IP、HTTP 端口和启动状态。
3. App 选择“真实设备”，默认“系统路由（手机热点）”。
4. 点击“发现设备”；如固件已广播 `_wifi-control._tcp` 且热点支持组播，候选设备出现。选择后填入地址，再点击“连接”。
5. 无发现结果时，手动输入串口显示的 IP/端口；不能把 192.168.4.1 当作所有热点的默认板端地址。

App 的设置按钮打开系统设置；用户负责热点启停与网络选择。厂商可能将热点选项放在不同位置，按钮不等于自动配置热点。

## 普通无线局域网 / 开发板热点

手机与板端连接同一 WLAN，选择“自动（优先 WiFi）”或“指定 WiFi 网络”。后者将客户端 socket 绑定到已连接 WiFi，适用于 WiFi 没有互联网、手机同时开启蜂窝数据的情况。

开发板 SoftAP 作为备用拓扑，手机手动加入板端热点后也可使用这两种路由。具体 IP 以固件配置为准。

## 权限与发现

Android 17/API37 上首次真实连接或发现前请求局域网权限；拒绝后可以用模拟模式，并可进入“应用权限”重新授权。回到前台时检查权限撤回，不自动重放控制命令。

Android 6–16 正常模式使用 INTERNET 与网络状态权限。当前 App 不扫描 WiFi AP，不需要为发现外设申请定位。人工打开 Android16 的局域网保护 opt-in 属于额外开发者测试模式，见[网络与权限说明](../design/network-and-permissions.md)。

发现是 mDNS/NSD 服务发现，不是“列出所有已连接热点的设备”。没有广播、AP 隔离或组播受限时不会列出设备，仍可手动地址连接。候选设备必须在连接后通过协议和设备描述校验。

## PC 模拟 HTTP 服务

见 [模拟服务说明](../../tools/mock-device/README.md)。手机与 PC 在同一网络，PC 显式绑定自己的局域网 IP/端口，App 选择真实设备并输入该地址。安卓模拟器可使用 `10.0.2.2:8080` 访问 PC 默认服务。

## 排错

| 现象 | 检查 |
| --- | --- |
| 找不到设备 | 板端是否广播 mDNS、双方是否同网、热点是否隔离组播；尝试串口 IP |
| 地址无法解析 | 仅输入 IP/主机，不包含 http://；检查端口、板端当前 DHCP 地址 |
| 没有已连接 WiFi | 手机提供热点时用系统路由，连接外部 AP 时用指定 WiFi |
| 局域网权限拒绝 | 应用权限重新授权；模拟模式不需要此权限 |
| 控制结果未知 | 看重新读取的确认状态，不反复点击切换来猜测结果 |
| 只读/不支持类型 | 按能力描述显示；不能把传感器或未知属性当开关 |
| 界面显示开启但负载不动 | 回报是逻辑输出；检查固件驱动、有效电平、接线和实际反馈 |

进入后台暂停周期轮询，回前台重新读取；修改连接配置会断开旧会话。应用不会因旋转屏幕或重新打开而自动执行保存的命令。
