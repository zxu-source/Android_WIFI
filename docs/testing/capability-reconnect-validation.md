# v1.1.1 精简清单入口

日期：2026-10-16。版本：1.1.1，versionCode=3。根据用户明确要求，移除占据设备信息卡空间的手动清单刷新功能，不新增替代按钮。

## 行为约定

- 设备信息卡不再显示“更新功能清单”；对应 UI 回调和 ViewModel 强制重载方法一并删除。
- 每次连接仍自动获取 device 清单与 state；需要主动重载时使用“断开”再“连接”，或已有的“重新连接”。
- 保留 capabilitiesRevision 变化、设备重启和协议错误后的自动重载与一致性校验。
- “读取状态”继续保留；正常连接下不强制重新加载未变化的清单。无版本号旧固件的纯改名/改范围通过重新连接获取。
- 空清单提示改为断开重连，使用说明与协议说明同步更新。原 v1.1 验证与截图作为历史记录保留，不冒充新版界面。

## 验证范围

JVM 回归覆盖旧固件名称变化时普通状态读取不重载、断开重连后按 device→state 顺序重新加载且不发送控制；既有测试继续覆盖清单版本自动更新、移除外设、不一致和回退保护。

模拟器新增 UI 回归检查，验证设备摘要存在但手动清单按钮不存在，同时保留重连与状态读取入口；动态新增灯和 Activity 重建测试继续执行。

首轮模拟器执行有一项测试在操作结束后的清理步骤失败：LazyColumn 已回收远处的 connect 节点，旧测试直接 performScrollTo 无法定位。已将两处清理操作改为列表 performScrollToNode，随后执行完整回归。该修正仅涉及测试定位，不修改产品行为。

最终实际结果：

- `:app:testDebugUnitTest`：38 项通过，0 失败、0 跳过；包含启用本机模拟 HTTP 服务的集成用例。
- `:app:connectedDebugAndroidTest`：Android 17 / API37 模拟器 10 项通过，0 失败、0 跳过；包含本次无刷新按钮回归、动态新增外设、HTTP 与本地 NSD 测试。
