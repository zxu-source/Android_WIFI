## 二、Android 系统开发与应用

随着网络时代以及 4G 时代的到来，智能移动终端已经成为人们生活中必不可少的一部分，并且在潜移默化地改变着人们的生活方式。将智能手机与控制系统相结合，大大增加了服务管理平台的便携性，为实现真正的移动通信方式提供了可能。

Android 是 2007 年 11 月由 Google 公司牵头组建的开放手机联盟（Open Handset Alliance）发布的智能移动设备软件平台。其前所未有的标准化和开放性，使 Android 操作系统成为一套真正意义上的开放性移动设备综合平台。

Android 采用层叠式软件架构，包括 Linux 内核层、函数库和组件库以及虚拟机组成的中间层，以及应用程序框架和应用程序组成的上层，如图 27-1 所示。

图 27-1 Android 平台结构（自上而下）：

```text
应用程序
应用程序框架
函数库、组件库、数据库等
Linux 内核层
```

Android 以 Java 作为开发语言，以开源 IDE Eclipse 作为开发环境，使用 Android SDK、Java 开发包 JDK 和开发插件 ADT 进行软件开发与调试。如此强大的开发平台能够满足手机终端的 Java 应用开发。

图 27-2 Android 开发环境搭建流程：

```text
JDK 安装与 Java 开发环境配置
  → Eclipse 和 Android SDK 的安装与配置
  → 安装和配置 ADT
```

Android 应用程序以 Android API 组件为基础进行开发，主要组件包括当前活动程序 Activity、应用程序组件 Service 等。请同学们自行查找资料，熟悉组件的功能与应用，并设计、初步实现一个 Android 系统的开发。

## 三、Android 系统与无线 WiFi 模块的通信

本实验要求实现一个基于 Android 手机的无线 WiFi 控制系统。Android 手机可以利用周围的无线网络资源，与其他设备交互并实施控制，为现有智能控制系统提供新的控制方法，在物联网开发与应用中具有重要意义。

总体设计思路：以嵌入式微处理器为核心的控制模块提供服务，与用户的 Android 手机通信。手机作为其他设备的管理器，提供交互界面，例如遥控停车入库、入位，或远程检查并控制家居灯光和电器。

这是一个 C/S 结构的系统：以嵌入式微处理器为核心的控制器作为服务器，Android 手机作为客户端。

图 27-3 系统总体结构图（语义整理）：

```text
以太网 ── WLAN
             ├── 智能终端（手机）
             ├── 车辆控制
             ├── 开关控制
             └── 视频监控
```

原图展示 WLAN 连接手机与多个控制/监控场景；它并未规定本实验必须实现车辆控制、视频监控或互联网连接。

## 六、本项目解释与用户澄清

用户明确：**下位机是带 WiFi 的遥控开关/外设控制器，用 WiFi 遥控外设；不是控制 WiFi 的启停。**

据此，第五章“WiFi 开关的开启与闭合”在本项目中落实为 ESP8266 收到无线命令后操作外设的开/关状态，例如点亮/熄灭 LED，或控制继电器的吸合/释放。不能将“已连接 WiFi”“已发送命令”当成外设控制成功。
